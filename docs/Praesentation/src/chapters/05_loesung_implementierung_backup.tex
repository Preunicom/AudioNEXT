\section{Lösung / Implementierung}
\begin{frame}{Lösung / Implementierung - Audio - Takterzeugung [Hafeneder]}
    \begin{itemize}
        \item Pmod I2S2 im Slave Mode: MCLK, SCLK und LRCK werden vom FPGA erzeugt
        \item 24 Bit Nutzungsdaten pro Kanal, Rest '0'
        \item \textbf{MCLK} = 24{,}576 MHz
        \item MCLK/LRCK Ratio = 256 \ra  \textbf{LRCK} = 96 kHz Samplingrate (Double-Speed Mode)
        \item SCLK/LRCK Ratio = 64 \ra  \textbf{SCLK} = 6{,}144 MHz
        \item Implementierung in \texttt{aud\_i2s\_clk\_gen.vhd}:
        \begin{itemize}
            \item SCLK: 1-Bit-Zähler togglet alle 2 MCLK-Takte \ra Periode = 4 MCLK
            \item LRCK: 7-Bit-Zähler togglet alle 128 MCLK-Takte \ra Periode = 256 MCLK
        \end{itemize}
        \item Takte nur aktiv wenn \texttt{i\_sen = '1'} (Sampling ist aktiviert)
    \end{itemize}
\end{frame}
\begin{frame}{Lösung / Implementierung - Audio - CDC \& Pufferung [Hafeneder]}
    \begin{itemize}
        \item Zwei Taktdomänen: \textbf{24{,}576 MHz} (Audio (MCLK)) und \textbf{100 MHz} (AXI Wrapper)
        \item \texttt{aud\_i2s\_sync}: 2-Flip-Flop Synchronisierer für das externe, asynchrone Signal \texttt{i\_data} \ra verhindert metastabile Zustände
        \item \texttt{aud\_channel\_buf}: AXI-Stream FIFO (Xilinx FIFO Generator 13.2)
        \begin{itemize}
            \item Schreibseite: 24{,}576 MHz (Audio)
            \item Leseseite: 100 MHz (AXI)
            \item getrennte FIFOs für linken und rechten Kanal
        \end{itemize}
        \item Data Overrun Flag (DOL/DOR) wenn ein neuer Sample anliegt aber der FIFO voll (nicht bereit) ist
    \end{itemize}
\end{frame}
